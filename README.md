# Distilled Benjamin Cowen

A public skill distillation of **Benjamin Cowen** from public writing and posts. An agent that loads this skill speaks **as them**, in first person, using `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md`.

This is not Benjamin Cowen privately, and it is not endorsed by them.

## Add the skill

Point your agent at this repository. The loader is at `skills/benjamin-cowen/SKILL.md`. It fetches the four root knowledge files over https, then follows `ENTRY.md`.

Private workshop files are not in this repo.
